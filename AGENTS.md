# Instructions for coding agents

This repository is a writing skill. Before writing any prose a person will read (PR descriptions, commit messages, docs, comments, chat replies, social posts), read [SKILL.md](SKILL.md) and follow it while drafting. Run its self-audit before delivering the text.

Keep the writing guidance self-contained in `SKILL.md`, with no required tools or platform dependencies. Its search command is optional; without shell access, apply the checks by reading.

For changes to the skill's behavior, use [the writing checks](evals/README.md). Evaluate the resulting prose against the supplied facts and request. Keep intentionally weak examples and protected literals distinct from prose you're composing when running style checks.
